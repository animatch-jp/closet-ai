# CLOSET.AI

手持ちの服を撮るだけで、天気と予定に合わせたコーデを提案するWebアプリ。

- 今日のコーデ / AIスタイリストに相談 / 1週間コーデ / 憧れコーデ再現 / クローゼット診断
- 相談：服の相談はすぐ動くしくみで答える。「なんでも話せるAI」を読みこむと、端末の中で動く小さな言語モデル（LFM2.5-350M・約300MB）で自由に話せる。
- 写真の読み取りはブラウザの中で動くAI（CLIP・Transformers.js）。写真は外に送られません。
- 天気データ：Open-Meteo.com（CC BY 4.0、非商用の無料版）
- 見本の写真：Unsplash（撮影者はページ下に表示）
